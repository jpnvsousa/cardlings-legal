# cardlings-legal

Privacy policy and legal links for the Cardlings game, served by GitHub Pages at
https://jpnvsousa.github.io/cardlings-legal/.

`privacy.html` and `terms.html` are generated: their sources are `docs/store/PRIVACY_POLICY.md` and
`docs/store/TERMS.md` in the game's repository (`pnpm privacy:html`), never edited here.
